Intelligent Air Pressure Control 2023

A prototype for an intelligent air pressure control system for tires in agricultural equipment using linear (PID) control strategies.

Developed using an ARM cortex processor in a dual core STM32 board. Utilized CAN, and serial protocols for sensor communication and a NodeMCU device for internet connectivity and online data visualization.
